Alternatif: jalankan lewat Console
  1. Buka instagram.com dan pastikan sudah login.
  2. Tekan F12, lalu pilih tab Console.
  3. Salin script dengan tombol di bawah, tempel di Console, lalu tekan Enter.
  4. Jika Chrome menolak paste, ketik allow pasting, tekan Enter, lalu tempel kembali.

Butuh langkah yang lebih rinci? Baca panduan lengkap. Bookmark tidak dapat dijalankan dari aplikasi Instagram. Jika langkah di atas tidak berhasil, gunakan tab dengan data ekspor dari aplikasi Instagram.

Password tidak diminta. Script berjalan di browser kamu menggunakan sesi Instagram yang sudah login dan tidak mengirim data ke server lain. Gunakan secukupnya (1–2 kali sehari) untuk menghindari pembatasan sementara dari Instagram.

Satu username per baris. Format @username dan link profil juga diterima.

Belum punya data?
Cara mengekspor data dari Instagram
  1. Buka aplikasi Instagram, masuk ke Profil, menu ☰, lalu Pusat Akun.
  2. Pilih Informasi dan izin Anda, Ekspor informasi Anda, lalu Buat ekspor.
  3. Pilih akun, lalu Ekspor ke perangkat.
  4. Di Sesuaikan informasi, pilih hanya Pengikut dan mengikuti.
  5. Atur Rentang tanggal: Sepanjang waktu dan Format: JSON, lalu mulai ekspor.
  6. Setelah notifikasi diterima, unduh file ZIP dan unggah di sini.

Hasil setiap pemeriksaan disimpan di browser. Saat data yang lebih baru diunggah, aplikasi akan menampilkan akun yang berhenti mengikuti sejak pemeriksaan sebelumnya.
