Cara menggunakan Cek Unfollow

Pilih perangkat yang kamu gunakan. Pemasangan cukup dilakukan sekali, setelah itu pemeriksaan bisa dijalankan kapan saja.

Komputer Android iPhone / iPad Unggah file Tanya jawab

Komputer / Laptop

Gunakan Google Chrome, Microsoft Edge, atau Firefox.

Bagian 1 Pasang bookmark (sekali saja)

  1. Tampilkan bookmark bar

    Tekan Ctrl Shift B (Mac: ⌘ Shift B). Bookmark bar muncul di bawah kolom alamat.

  2. Seret tombol berikut ke bookmark bar

    Tahan klik pada tombol, geser ke bookmark bar, lalu lepaskan.

    Cek Unfollow
  3. Pastikan bookmark sudah ada

    Bookmark bernama Cek Unfollow akan terlihat di bookmark bar.

    Tidak bisa diseret? Klik kanan tombol di atas, pilih Salin alamat link. Lalu klik kanan bookmark bar, pilih Tambahkan halaman…, isi nama Cek Unfollow, tempel di kolom URL, dan simpan.

Bagian 2 Jalankan pemeriksaan

  1. Buka instagram.com dan login

    Gunakan browser yang sama dengan tempat bookmark dipasang. Buka instagram.com

  2. Klik bookmark Cek Unfollow

    Panel Cek Unfollow muncul di atas halaman Instagram dan mulai mengambil data.

  3. Tunggu hingga selesai

    Biasanya 1–3 menit, tergantung jumlah akun. Biarkan tab tetap terbuka.

  4. Baca hasilnya

    Klik angka di panel ringkasan atau tab di atas daftar untuk berpindah kategori. Tekan Esc untuk kembali ke Instagram.

Android

Gunakan browser Google Chrome. Cara ini tidak dapat dijalankan dari aplikasi Instagram.

Bagian 1 Pasang bookmark (sekali saja)

  1. Buka halaman ini di Chrome

    Jika halaman dibuka dari WhatsApp atau Instagram, ketuk ⋮ lalu Buka di Chrome.

  2. Salin kode bookmark

    Ketuk tombol berikut. Kode akan tersalin otomatis.

  3. Simpan halaman ini sebagai bookmark

    Ketuk ⋮ di pojok kanan atas, lalu ketuk ikon bintang ☆.

  4. Buka pengaturan bookmark

    Di bagian bawah layar muncul notifikasi Bookmark disimpan. Ketuk Edit.

    Notifikasi terlewat? Ketuk ⋮, pilih Bookmark, cari bookmark tersebut, tekan lama, lalu pilih Edit.
  5. Ubah nama dan alamat

    Ganti Nama menjadi Cek Unfollow. Hapus seluruh isi kolom URL, tekan lama, lalu pilih Tempel.

  6. Simpan

    Ketuk tombol kembali ←. Perubahan tersimpan otomatis.

Bagian 2 Jalankan pemeriksaan

  1. Buka instagram.com di Chrome dan login

    Jika diminta membuka aplikasi, pilih tetap di browser. Buka instagram.com

  2. Ketik nama bookmark di kolom alamat

    Ketuk kolom alamat, lalu ketik Cek Unfollow.

  3. Ketuk bookmark pada daftar saran

    Pilih saran yang memiliki ikon bintang ☆.

    Jangan tekan Enter. Menekan Enter akan membuka pencarian Google, bukan menjalankan bookmark.
  4. Tunggu hingga selesai

    Biasanya 1–3 menit. Jangan berpindah aplikasi agar proses tidak terhenti.

iPhone / iPad

Gunakan browser Safari. Cara ini tidak dapat dijalankan dari aplikasi Instagram.

Bagian 1 Pasang penanda (sekali saja)

  1. Buka halaman ini di Safari

    Jika halaman dibuka dari WhatsApp atau Instagram, pilih Buka di Safari.

  2. Salin kode bookmark

    Ketuk tombol berikut. Kode akan tersalin otomatis.

  3. Simpan halaman ini sebagai penanda

    Ketuk ikon Bagikan (kotak dengan panah ke atas), pilih Tambah Penanda, lalu ketuk Simpan.

  4. Buka daftar penanda

    Ketuk ikon buku Penanda. Pada iOS terbaru, ikon ini ada di menu ⋯.

  5. Edit penanda

    Ketuk Edit di pojok bawah, lalu ketuk penanda yang baru disimpan.

  6. Ubah judul dan alamat

    Ganti judul menjadi Cek Unfollow. Hapus alamatnya dengan tombol ⓧ, tekan lama kolom alamat, lalu pilih Tempel.

  7. Simpan

    Ketuk Selesai.

Bagian 2 Jalankan pemeriksaan

  1. Buka instagram.com di Safari dan login

    Jika diminta membuka aplikasi, pilih tetap di browser. Buka instagram.com

  2. Buka Penanda dan ketuk Cek Unfollow

    Panel Cek Unfollow muncul di atas halaman Instagram dan mulai mengambil data.

  3. Tunggu hingga selesai

    Biasanya 1–3 menit. Jangan berpindah aplikasi agar proses tidak terhenti.

Unggah file ekspor Instagram

Cara resmi dari Instagram dan dapat dipakai di semua perangkat, termasuk HP. Prosesnya lebih lama karena perlu menunggu file dari Instagram.

Bagian 1 Minta data dari Instagram

  1. Buka Pusat Akun

    Di aplikasi Instagram: Profil → menu ☰ → Pusat Akun.

  2. Pilih ekspor informasi

    Informasi dan izin Anda → Ekspor informasi Anda → Buat ekspor, lalu pilih akun.

  3. Ekspor ke perangkat

    Pilih Ekspor ke perangkat.

  4. Atur isi ekspor

    Di Sesuaikan informasi, pilih hanya Pengikut dan mengikuti. Atur Rentang tanggal ke Sepanjang waktu dan Format ke JSON.

    Format harus JSON. Jika memilih HTML, file tetap dapat dibaca, tetapi tanggal mengikuti mungkin tidak tampil.
  5. Mulai ekspor

    Ketuk Mulai ekspor. Instagram akan mengirim notifikasi atau email saat file siap, biasanya dalam beberapa menit hingga beberapa jam.

  6. Unduh file

    Buka notifikasi atau email tersebut, lalu unduh file ZIP-nya.

Bagian 2 Unggah ke Cek Unfollow

  1. Buka halaman Cek Unfollow

    Buka halaman utama, lalu pilih tab Unggah file.

  2. Pilih file ZIP

    Ketuk area unggah dan pilih file ZIP yang sudah diunduh. File tidak perlu diekstrak.

  3. Hasil langsung tampil

    Simpan file ekspor berikutnya di lain waktu dan unggah kembali untuk melihat siapa yang berhenti mengikuti.

Tanya jawab

Masalah yang sering ditemui dan cara mengatasinya.

Apakah aman? Apakah password saya diminta?

Password tidak pernah diminta. Script berjalan di browser kamu sendiri menggunakan sesi Instagram yang sudah login, dan tidak mengirim data ke server lain. Kode sumbernya terbuka dan dapat diperiksa di GitHub.

Bagaimana memastikan saya memakai versi asli?

Pasang bookmark hanya dari alamat resmi haidarhafiz21.github.io/cek-unfollow. Jangan memasang bookmark atau menempel script yang dikirim orang lain lewat chat, karena penipu sering meniru alat seperti ini untuk membajak akun Instagram.

Muncul pesan "Data pengikut belum lengkap" atau "Perubahan tidak wajar"

Ini pengaman agar aplikasi tidak salah menuduh seseorang berhenti mengikuti. Jika Instagram tidak mengirim seluruh daftar pengikut, hasil pemeriksaan tersebut tidak dicatat ke riwayat. Tunggu beberapa saat lalu jalankan Cek ulang. Jika penurunannya memang nyata (misalnya akun palsu dihapus Instagram), pilih Tetap simpan.

Muncul pesan "Belum login"

Login terlebih dahulu ke instagram.com di browser yang sama, lalu jalankan bookmark kembali. Login di aplikasi Instagram tidak berlaku untuk browser.

Muncul pesan "Instagram membatasi permintaan"

Instagram membatasi sementara karena terlalu banyak permintaan. Tunggu sekitar 1–2 jam sebelum mencoba lagi. Gunakan pemeriksaan secukupnya, maksimal 1–2 kali sehari.

Bookmark tidak muncul saat mengetik di Android

Pastikan nama bookmark sudah diubah menjadi Cek Unfollow. Coba ketik sebagian saja, misalnya Cek Un, lalu gulir daftar saran untuk mencari item berikon bintang.

Kode tidak bisa ditempel atau bookmark tidak tersimpan

Beberapa browser di HP membatasi panjang alamat bookmark. Jika langkah pemasangan tidak berhasil, gunakan cara Unggah file yang dapat dipakai di semua perangkat.

Tidak terjadi apa-apa saat bookmark diklik

Pastikan halaman yang sedang terbuka adalah instagram.com. Jika bookmark dipasang sebelum pembaruan terakhir, hapus bookmark lama lalu pasang ulang dari halaman ini.

Kenapa daftar "Berhenti mengikuti" masih kosong?

Daftar ini terisi mulai pemeriksaan kedua. Hasil setiap pemeriksaan disimpan di browser, lalu dibandingkan dengan pemeriksaan berikutnya. Gunakan browser yang sama setiap kali memeriksa.

Bisakah dijalankan dari aplikasi Instagram?

Tidak. Aplikasi Instagram tidak mendukung bookmark. Gunakan instagram.com di Chrome atau Safari, atau gunakan cara Unggah file.

Jumlah akun di hasil sedikit berbeda dengan di profil

Selisih 1–2 akun itu wajar. Angka di profil Instagram ikut menghitung akun yang sedang dinonaktifkan atau dibatasi, tetapi akun tersebut tidak ditampilkan di daftar mana pun, termasuk di aplikasi Instagram sendiri. Jika satu akun mutual sedang nonaktif, angka pengikut dan mengikuti sama-sama berselisih 1. Jika selisihnya besar, jalankan Cek ulang beberapa saat kemudian.

Mulai pemeriksaan

Data diproses di browser dan tidak dikirim ke server. Tidak berafiliasi dengan Instagram atau Meta.
